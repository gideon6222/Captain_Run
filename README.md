# Wick

You are a candle. Dip through arches of coloured wax, dodge the blades and the heat, and
carry the best candle you can to the chandler.

Play: https://gideon6222.github.io/Captain_Run/

Built with Vite, TypeScript and three.js; installed to a phone as a PWA. See `CLAUDE.md` for
the shape of the repo and `NOTES.md` for the design decisions.

> The repo is still named `Captain_Run` after the viking runner it used to hold, through
> v0.3.0. Renaming it is a one-click change in GitHub settings and costs nothing here -
> `base: './'` means no path in the build depends on it - so it is left alone until asked.

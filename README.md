# Candle Gift

Run a tray of candles down the line. Dip them in coloured wax, sprinkle glitter, press a
shape, tie a bow, dodge the barriers and saws — then sell the lot at the gift table.

Play: https://gideon6222.github.io/Captain_Run/

Modelled on **Candle Gift** by Rollic Games. Built with Vite, TypeScript and three.js;
installed to a phone as a PWA. See `CLAUDE.md` for the shape of the repo and `NOTES.md` for
the design decisions and what was taken from the reference.

> The repo is still named `Captain_Run` after the viking runner it used to hold. Renaming it
> is a one-click change in GitHub settings and costs nothing here — `base: './'` means no
> path in the build depends on it — so it is left alone until asked.

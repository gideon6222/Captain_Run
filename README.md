# Captain Run

Lead a viking warband up the mountain. Drag to steer, forge the axe, break the jotunn.

Play: https://gideon6222.github.io/Captain_Run/

A phone-first PWA built with Vite and three.js, installed to the home screen. `npm run dev`
to play locally, `npm test` for the unit tests, `npm run e2e` for the smoke tests.
See `NOTES.md` for design and deploy notes and `CLAUDE.md` for the shape of the repo.
